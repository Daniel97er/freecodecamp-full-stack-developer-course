Web Development Fundamentals

A practical introduction to building structured, accessible and responsive websites with HTML and CSS.

Introduction

Web development is the process of creating websites and applications that run in a web browser. Two essential technologies used in this process are HTML and CSS.

HTML provides the structure and meaning of a webpage, while CSS controls its visual presentation and layout. Together, they form the foundation of modern web design.

CORE CONCEPT

HTML defines what content exists. CSS defines how that content looks and behaves across different screen sizes.

  • HTML structures the content.
  • CSS controls the appearance.
  • Responsive design adapts layouts to different devices.
HTML Document Structure

Every HTML document follows a basic structure. It begins with a document type declaration, followed by the root HTML element.

The head element contains information about the document, such as its title, character encoding and linked stylesheets. The body element contains the visible page content. 

<!DOCTYPE html>




My Website



Hello World

The viewport meta tag is important for responsive layouts. It ensures that the browser uses the device's actual width when displaying the page. 

<meta name="viewport"

content="width=device-width, initial-scale=1.0">
HTML Elements

HTML elements are the building blocks of a webpage. Most elements consist of an opening tag, content and a closing tag.

Elements communicate the purpose of their content. Semantic HTML uses meaningful tags to describe the different parts of a document. 

<header>Website Header</header>


Main Content


Content Section


Website Footer

Common HTML elements include:

  • <h1> to <h6> for headings.
  • <p> for paragraphs.
  • <a> for hyperlinks.
  • <img> for images.
  • <ul> and <ol> for lists.

Semantic elements improve document organization and help assistive technologies understand the page structure.

CSS Fundamentals

CSS stands for Cascading Style Sheets. It is used to control the visual appearance of HTML elements, including colors, typography, spacing and positioning.

A CSS rule consists of a selector and a declaration block. The selector identifies which HTML elements should receive the specified styles. 

h1 {

color: #72b4ff;
font-size: 2rem;
margin-bottom: 1rem;
}

CSS selectors can target elements in several ways. Classes are particularly useful when multiple elements should share the same styling. 

.card {

background-color: #10233d;
padding: 1.5rem;
border-radius: 0.75rem;
}

Some important CSS concepts are:

  • Selectors determine which elements are styled.
  • The box model describes element dimensions and spacing.
  • Flexbox helps arrange elements along an axis.
  • Grid creates layouts using rows and columns.
Responsive Design

Responsive web design ensures that websites remain usable on different devices, including smartphones, tablets and desktop computers.

Instead of creating a separate website for every device, responsive layouts adapt to available screen space. 

.container {

width: 100%;
max-width: 1200px;
margin-inline: auto;
padding: 1rem;
}

CSS media queries allow developers to apply different styles depending on the characteristics of the device or viewport. 

@media (max-width: 768px) {

.container {
padding: 0.75rem;
}
}

Important responsive design techniques include:

  • Using flexible layouts instead of fixed widths.
  • Choosing relative units such as rem and percentages.
  • Making images scale within their containers.
  • Using media queries when the layout needs to change.
Accessibility

Web accessibility means designing websites that can be used by as many people as possible, including people with visual, auditory, motor or cognitive disabilities.

Accessible websites provide alternative ways to perceive and interact with information. This includes keyboard navigation, screen reader support and sufficient color contrast.

Important accessibility practices include:

  • Using semantic HTML elements.
  • Providing descriptive alternative text for meaningful images.
  • Maintaining sufficient contrast between text and backgrounds.
  • Ensuring that interactive elements work with a keyboard.
  • Providing visible focus indicators.
<button type="button">

Open Navigation

Accessibility should be considered from the beginning of a project rather than added as an afterthought. A well-structured website benefits all users.

BEST PRACTICE

Never rely on color alone to communicate important information. Combine colors with text, icons or other visual indicators.
